# TheLingo Design System & Direction

## North Star

The page feels like entering a high-end competitive game lobby for language fluency. It sells real skill status first, then proves the learning mechanism with authentic, non-slop product UI.

## Conversion Argument

- **Audience**: Language learners who demand real conversational capability, clear progress metrics, and authentic cultural communities.
- **Promise**: Turn language capability into an unassailable rating (FS - Fluency Score) that moves as skill improves.
- **Mechanism**: Blind head-to-head AI judging, avatar teaching, and language-specific micro-societies.
- **Proof**: Honest, premium CSS-built interface scenes matching actual product behavior. No fake countdowns, no generic stock cards.
- **Action**: Claim your rank with an email address and join your language cohort.

## Consolidated Visual System

- **Arena Ink**: `#101114` (Near-black)
- **Paper Warm**: `#f6f6f2` (Warm cream)
- **Primary Accent (Action / You)**: `#4655ff` (Indigo)
- **Secondary Accent (Energy / Win State)**: `#ff5f49` (Coral)
- **Interface Line**: `#d8d9d3`
- **Typography**: 
  - Display: Heavy geometric display sans for main headlines.
  - Body & Eyebrows: Clean humanist sans stack (eyebrows set in bold, letter-spaced uppercase sans).
  - Monospace: Reserved strictly for numeric data (rank numbers, timers, FS points).
- **Badges & Tags**: Integrated header tags with soft indigo/coral tint backgrounds (no neon strokes, no floating debug pills).
- **Icons**: Flat vector illustration style matching Nova's rounded avatar design.
- **Spacing Grid**: Strict 8px scale (`8px`, `16px`, `24px`, `32px`, `48px`, `64px`, `96px`).
- **Shadows**: Firm offset scorecard shadows (`5px 5px 0 var(--ink)`).

## Signature Interaction

The central visual is a live blind verdict: 1v1 equal prompt submission -> 1.2s blind evaluation -> +184 FS rating jump & Silver II promotion.

## Motion Guidelines

Hardware-accelerated micro-animations (`cubic-bezier(0.16, 1, 0.3, 1)`). High-energy-but-premium, never bouncy or cartoonish. Respect reduced-motion preferences.
